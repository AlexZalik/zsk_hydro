Свердловина й режим циркуляції

Вертикальні глибини та долото

TVD для заданого MD визначається автоматично за лінійним співвідношенням TVD/MD вибою. Повний MD свердловини дорівнює сумі довжин її інтервалів.

Реологія трубного простору

Введіть покази шкали віскозиметра, а не перераховані напруження.

Реологія затрубного простору

Гідравлічна модель

Насадки долота

Діаметри у 1/32 дюйма. Для невикористаних насадок — 0.

Реологія

Перерахунок показів віскозиметра, пластичної в’язкості PV та динамічного напруження зсуву YP.

Кути 600 / 300 → PV та YP

PV = θ600 − θ300
YP, дПа = (2 × θ300 − θ600) × 4,788

PV та YP → кути 600 / 300

θ300 = PV + YP / 4,788
θ600 = 2 × PV + YP / 4,788

Результати оновлюються під час введення. Дробові покази відображаються без округлення до цілих кутів. Це окремий перерахунок; реологія труб і затрубу задається у вкладці «Вхідні дані».

Порядок інтервалів і елементів — від устя до вибою. Секції автоматично утворюються на перетині меж свердловини й колони. Для автоматичного розміщення замків задайте їх OD, ID, крок та довжину. Замок стоїть у кінці кожного повного кроку; кількість = floor(L / крок). Неповний залишок — тіло труби. L загальна вже включає замки. Якщо замки задані окремими рядками, залиште їх параметри в рядках тіла нульовими, щоб не врахувати двічі.

Конструкція свердловини

Бурильна колона та КНБК

Самостійний блок з окремими вихідними даними, як у Excel. Коефіцієнт H12 у вихідній формулі використовує основну подачу насосів із вкладки «Вхідні дані».

Умови очищення

Винесення шламу

Спрощений розрахунок із вихідного файлу. Втрати визначаються лише для бурильних труб довжиною H − LОБТ; опір секції ОБТ у формулі відсутній. Відображені тиски — гідростатичний тиск ± зміна тиску від СПО.

Параметри спуско-підіймальних операцій

Свабування та поршнювання

Каталог труб і замків ТМК

Довідкові характеристики українською мовою · 36 варіантів геометрії та висадки · друковані сторінки 12–47 каталогу.

OD — зовнішній діаметр; ID — внутрішній. Розміри під ключ не є повною довжиною замка й не замінюють її у гідравлічному розрахунку. Каталог — довідник; введені параметри колони він автоматично не змінює.

Характеристики тіла бурильної труби

Сумісні замки за каталогом

Кожний запис прив’язаний до геометрії, висадки й груп міцності труб на відповідній сторінці. Варіанти з різною міцністю матеріалу замка наведені окремо.

Про джерело

Числові характеристики відтворені з технічного каталогу ТМК. Заголовки та пояснення перекладені українською; заводські позначення збережені. Тире означає, що значення не наведене. Помітні неузгодженості геометрії позначені біля таблиць; значення джерела не виправлялися.

Перевірка за API RP 13D · 17.11.2026

Джерело: наданий API RP 13D, 8th Edition, April 2026. Нижче наведені друковані сторінки стандарту. Назва моделі: Rheological model API 13D.

  • Реологія — рівняння (26)–(28), с. 30–32: τ₀ = 2θ3 − θ6; n = 3,32 log₁₀[(θ600 − τ₀)/(θ300 − τ₀)]; k = (θ300 − τ₀)/511ⁿ. Підтверджено наближене визначення за чотирма показами, окремо для труб і затрубу. Це не регресія за повною реограмою. Внутрішні τ₀ і k — у одиницях шкали; для звіту в Па та Па·сⁿ множник 1,067 × 0,4788026.
  • Стінка і тертя — (69), (71)–(76), (84)–(92), с. 53–60: Bт = (3n+1)/(4n); Bз = 1,5(2n+1)/(3n); Bx ≈ 1. Виправлено τw = 1,067τv замість 1,06τv за (74). Підтверджено fлам = 16/ReG для труб і затрубу. Турбулентна гілка використовує np, згладження — (89)–(90). Довільну межу режиму Reкрит + 800 вилучено.
  • Насадки — (100)–(102), с. 64: P = ρQ²/(12042 Cd² TFA²), у польових одиницях. TFA = πΣd²/(4·1024) in², d у 1/32 дюйма; Cd типово 0,98. Підтверджено.
  • ECD — спрощення (106), с. 66–67: ρECD = ρ + ΔPз/(g·TVD), з узгодженими SI-одиницями. Передбачено сталу густину (ESD = ρ), нульовий протитиск і відсутність впливу шламу. PVT, ексцентриситет, шорсткість та зміна реології з глибиною не враховані. TVD інтерполюється між заданими точками, а не за інклінометрією.
  • Геометрія і замки: тіло та замок розбиваються на межах інтервалів; кількість замків floor(L/крок). Тертя обчислюється окремо. Додаткові місцеві втрати Nξρv²/2, ξ = 2[(IDтіла/IDзамка)² − 1], — наближення вихідного HTML. Такої формули ξ у §7.4.14 API немає; ці втрати НЕ підтверджені методикою. Затрубні місцеві опори не враховані.
  • Очищення — частково: структура CCI відповідає (123)–(126), с. 83–84. Густина в ppg узгоджується з прикладами E.3–E.4 (CCI 0,20 та 1,38), хоча опис одиниць біля (123) неоднозначний. Успадкований блок використовує округлення 3,322 і 24,5. CCI ≥ 1 — добре; близько 0,5 — гранично; < 0,4 — погано. Осідання та винесення шламу залишені як неперевірені формули Excel: H12 залежить від основної подачі; це НЕ реалізація (115)–(121), де потрібна також товщина частинки.
  • СПО — не підтверджено: допоміжний блок Excel не відповідає повному §8: відсутній опір ОБТ, неоднозначний множник ((2n+1)/3 × n), не обґрунтовано 1,5 для швидкості. Для переробки потрібно визначити відкритий/закритий кінець колони та максимальну швидкість. Результати блока збережені з явним попередженням.
  • Одиниці та звіт: 1 атм = 0,101325 МПа. PV = θ600 − θ300 (cP); YP = (θ300 − PV) × 4,788 (дПа у відображенні); LSYP = 2θ3 − θ6 — як у початковому Excel, без додаткового множника 1,067. У звіті показані активні HB-параметри. Допоміжні модулі Excel зберігають власні старі перетворення і не охоплені підтвердженням основної гідравліки.
